# AI 사용 로그

이 프로젝트는 AI(Claude)를 활용해 만들었습니다. 아래는 어떤 작업에 왜 AI를 썼고, 결과를 어떻게 검증했는지에 대한 기록입니다. 검증은 모두 **저장소 안의 테스트와 스크립트로 다시 확인**할 수 있게 남겼습니다.

## 1. 사용 내역

| # | 사용 작업 | 사용 이유 | 검증 방법 |
|---|---|---|---|
| 1 | **설계**: 기능 4개를 API·DB 테이블·화면으로 나누는 구조 제안 | 대안 탐색 | 미션 문장("분석 → DB 저장 → AI 대화")과 기능별로 대조해 README 9장 대응표로 정리 |
| 2 | **Codyssey API 연동 코드** (OpenAI 호환 + Anthropic 호환) | 시간 절감 | Codyssey 콘솔의 코드 예제(주소 `/v1/chat/completions`, `Authorization: Bearer`, 모델 `gpt-5-mini` / Anthropic 설정의 `ANTHROPIC_BASE_URL`, 모델 `claude-sonnet-4`)와 요청 형식을 대조. 가짜 서버(httpx MockTransport)로 **주소·헤더·본문을 자동 검사** (`test_openai_compatible_request_format`, `test_anthropic_compatible_request_format`). 실제 연결은 `scripts/check_api.py`로 확인 |

| 8 | **재현성 확인** | 검증 | Python 3.10 + `requirements.txt`의 **최소 버전**(fastapi 0.110, pydantic 2.6, httpx 0.27, pandas 2.2) 환경과 최신 환경에서 테스트 20개 모두 통과 |

## 2. AI 결과를 그대로 쓰지 않고 고친 사례

1. **메모 검색어 버그** — 처음 코드는 "노동절에는"에서 조사 '에는'을 떼지 못해 메모 '노동절'을 찾지 못했습니다. 테스트(`test_find_ranges_parsing`, `test_memo_keyword_context`)가 실패해서 발견했고, 조사·서술어 처리 규칙을 고쳤습니다.
2. **'취소' 버튼이 사라지지 않는 문제** — 화면 캡처를 확인하다가, 수정을 마친 뒤에도 취소 버튼이 남는 것을 발견했습니다. CSS의 `display`가 HTML `hidden` 속성을 덮어쓴 것이 원인이었고, `[hidden]{display:none !important}`로 고쳤습니다.
3. **상태 표시 문구** — 키만 넣어도 "AI 연결됨"으로 표시돼, 잘못된 키여도 연결된 것처럼 보였습니다. 실제 연결 여부는 호출해 봐야 알 수 있어서 **"AI 키 설정됨"** 으로 바꾸고, 연결 확인용 `scripts/check_api.py`를 추가했습니다.
4. **대체 답변 개선** — 키가 없을 때 관련 기록을 날짜순으로 앞 10건만 보여 줘서 정작 중요한 날(폭설일)이 빠졌습니다. **메모가 있는 날과 최고·최저일을 먼저** 보여 주도록 바꾸고, '같은 요일 평균 대비 %'를 추가해 "평소보다 얼마나 적은가" 같은 질문에도 숫자로 답하게 했습니다.
5. **차트 라이브러리** — 처음엔 인터넷(CDN)에서 불러왔는데, 인터넷이 막힌 환경에서는 차트가 그려지지 않았습니다. Chart.js 파일을 프로젝트에 포함(MIT 라이선스 표시)했습니다.
6. **gpt-5 계열 매개변수** — `temperature`, `max_tokens`를 고정하면 gpt-5 계열에서 거부될 수 있어 OpenAI 호환 요청에서는 빼고 기본값을 쓰도록 했습니다(Anthropic 호환은 필수인 `max_tokens`만 지정).

## 3. 최종 판단의 근거
- 기능이 제대로 동작한다는 판단은 **자동 테스트 20개**(`pytest -v`, 결과는 `docs/TEST_REPORT.md`)와 **실제 화면 캡처 14장**에 근거합니다.
- AI 답변의 숫자가 맞는지는 화면의 **'근거 보기'** 에서 AI에게 보낸 원자료와 직접 대조할 수 있습니다.
- 작업 환경에서는 Codyssey API에 접속할 수 없어 **실제 AI 응답은 확인하지 못했습니다.** 키를 넣은 뒤 `python scripts/check_api.py`로 연결을 확인하고, 실제 답변 화면을 캡처해 추가해야 합니다.
